These Apache-2.0 OpenDesign sources are derived from the WoowTech fork. The profile records the exact base and modified revisions. They add native single-entry MCP compare-and-swap updates; the source files are compiled by scripts/build-native-layer.mjs. All other daemon/web modules come from the pinned base image.

`profiles.mjs` selects a fixed reviewed host. The default remains the w2.4 image in `profile.json`; `omnigent-0.1.4.json` records the combined host's immutable image and source commit. The two existing MCP source files are byte-identical in both hosts, and `routes/mcp-servers.ts` is new in both. Each build receipt records the actual selected host instead of attributing a combined image to the older base.

The corresponding `*-mobile.json` profiles record the source commits and web-layer hashes for the mobile launcher fix. Each web layer contains explicit parent directory headers: a file-only tar can pass a local archive check but fail containerd overlay extraction. Both corrected hosts have passed a real sandbox pod pull and all 764 web-output hash checks. The actual source-built web manifests are available in the images at `/usr/local/share/woow/mobile-launchers-build.json`.
