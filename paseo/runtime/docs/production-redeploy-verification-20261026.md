## 正式管理頁追加驗收

後續建立專用臨時管理員，透過正式網站的正常登入表單取得工作階段。以沒有部署資源、排程不會自動開通的測試記錄，實際修改固定 chart／映像、按下儲存並重新載入，確認原生表單與後端儲存值一致；測試中沒有偽造登入 session 或停用平台保護。

再於兩台指定主機的真實管理表單按下 **Redeploy** 及確認按鈕，兩台均增加一個實際 Helm revision、回到 running，映像、chart、完整 values、持久卷、專案檔案及初始化對話均保留。包含這次 GUI 操作，每台共完成三次完整 Redeploy。含 Omnigent 主機的 Pi 原生預設設定檔雜湊在此次部署前後一致。

部署完成後，再以全新瀏覽器開啟原生外掛入口，不傳入 preferred model、不手動切換模型，Pi 預設模型完成第一則與後續回覆。測試代理已封存，設定檔雜湊未變。

驗收結束後，臨時帳號停用、移除權限及更換隨機密碼；原生登入表單拒絕舊密碼。另發布原生帳號快取失效通知，依 Odoo 實際 session 目錄結構確認沒有屬於這些帳號的已登入紀錄。專用測試記錄及本機暫存登入資料均清除，未建立新訂閱或轉移供應商帳號。

驗收程式的早期失敗另行保留：舊的 pending 測試記錄會被排程接手，後改用不會觸發開通的狀態；原生 revision 欄位預設為 1，不能當成「已部署」；Odoo 按鈕請求的路徑帶有 model／method，需要精確比對。被驗收程式攔下的請求不列為部署成功，修正後以真實 GUI、回傳結果及 Helm 狀態驗收。

## 外掛與模型對話

標準主機的 CLI Terminal、MCP Server、Paseo 入口在五種螢幕寬度的列表及詳細頁，實際點按開啟新分頁共 30 項通過。真實 stdio MCP 的狀態及三種模型目錄讀取成功，44 個 Paseo runtime 檔案與來源一致。

標準主機透過 Paseo 設定 GUI，使用該主機原有帳號，完成 Claude、Codex、Pi 各兩輪對話：

| Provider | 實測模型 | 第一則／後續回覆 |
| --- | --- | --- |
| Claude | `claude-haiku-4-5` | 通過／通過 |
| Codex | `gpt-6.1-sol` | 通過／通過 |
| Pi | `openrouter/cohere/north-mini-code:free` | 通過／通過 |

Claude 首次測試遇到另一程序正在更新 OAuth 的暫時錯誤；保留失敗證據，稍後單次重試才通過，沒有重設帳號或終止其他程序。這是暫時狀態恢復，並非本次新增程式修復。

含 Omnigent 的主機也使用自己的既有設定完成三種代理各兩輪對話：

| Provider | 實測模型 | 第一則／後續回覆 |
| --- | --- | --- |
| Claude | `claude-haiku-4-5` | 通過／通過 |
| Codex | `gpt-6.1-sol` | 通過／通過 |
| Pi | 工作區既有 LiteLLM 路由，`gpt-5.6-sol` | 通過／通過 |

此主機的 Pi 模型目錄只有兩條既有 LiteLLM 路由，不包含標準主機使用的 OpenRouter 模型。原預設路由在原生會話紀錄中回傳 HTTP 429／`litellm.RateLimitError`；使用相同工作區既有授權的另一條路由後，兩輪對話通過。後續有限次重測仍回傳 429，因此在這台主機的原生 `~/.pi/agent/settings.json` 設定已驗證可用的預設 provider／model；原路由仍保留，沒有宣稱上游限流已修復。使用全新瀏覽器、不手動指定模型，確認目錄標示的預設值及兩輪對話均通過。沒有從其他工作區搬移帳號或重設供應商登入。真實 stdio MCP 狀態及三種模型目錄讀取成功，44 個 Paseo runtime 檔案及四個原生入口 manifest 均通過檢查。

含 Omnigent 主機的四個外掛入口也在 320、390、720、721、1440px 的列表與詳細頁完成 40 項實際點按、新分頁及目的地檢查。兩台合計 70 項通過。

## 官方 Paseo App

從標準主機的設定頁實際按下配對，官方 App 顯示該 daemon 為 Online／Relay，連線身分與產生的配對一致。在官方 App 選擇 Codex `gpt-6.1-sol` 與 Default permissions，建立測試對話並完成兩輪回覆；第二輪保留第一輪標記。最後只封存本次建立的代理，並由 History 確認封存狀態。

這項驗證與設定頁的對話測試分開執行。OpenDesign 的 Basic 帳密僅送到該主機來源；官方 App 使用獨立瀏覽器 context，配對資料保留在記憶體，不刊登在證據或 repo 中。本次官方 App 對話只實測 Codex；不將設定頁的 Claude／Pi 結果擴大解讀為官方 App 全模型驗收。
